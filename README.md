# 省钱种田（mcd-farm-tycoon）

> 一句话：**把每次吃麦当劳，变成农场里的一格生长进度。**

一个基于麦当劳 MCP 的养成类 Skill。真实消费产生的热量变成作物成长的能量，
用券省下的钱变成购买农具的资金，收获的食材兑换成农场券再用于下次消费。

## 解决什么问题

省钱这件事有个尴尬：省下来的钱是散碎的、无感的，几块钱的优惠很难让人有成就感，
更难形成习惯。

这个 Skill 换了个包装 —— 把「省了 12 块」变成「我的小麦熟了」。

- **有目标**：不是抽象的省钱，而是具体的「再攒 264 kcal 就能收小麦」
- **有积累**：工具一次买入、永久提效，付出看得见
- **有节奏**：每周兑换上限把节奏拉回真实生活，不催你多吃

## 核心玩法

```
吃麦当劳 → 热量变能量 + 省额变农资金
              │                      │
              ↓                      ↓
        推进作物生长            购买农具提效
              │                      │
              └──────────┬───────────┘
                         ↓
                     成熟收获
                         ↓
              食材兑换农场券 → 下次消费抵扣
```

四条作物构成线性关卡：**生菜 → 小麦 → 鸡 → 猪**，
分别对应麦当劳的汉堡生菜、面包、鸡肉与猪肉。

## 安装方法

### 方式一：作为 MCP Client 的 Skill 使用（推荐）

1. **申请 MCP Token**
   访问 <https://open.mcd.cn/mcp>，手机号登录 → 「控制台」→「激活」→ 同意协议 → 复制 Token。

2. **配置 MCP Server**

   ```json
   {
     "mcpServers": {
       "mcd-mcp": {
         "type": "streamablehttp",
         "url": "https://mcp.mcd.cn",
         "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
       }
     }
   }
   ```

   > 替换 `YOUR_MCP_TOKEN` 后保存并启用。

3. **加载 Skill**：把 `SKILL.md` 放入 Skill 目录，或直接在对话中引用。

4. **开始使用**，说人话即可：

   ```
   我想种田，现在农场怎么样了？
   我刚点了一单麦当劳，帮我结算
   我想种小麦
   还差多少能量才能收获？
   ```

### 方式二：命令行直接运行

```bash
export MCD_MCP_TOKEN="你的Token"   # Windows: set MCD_MCP_TOKEN=你的Token

python scripts/cli.py status       # 农场状态
python scripts/cli.py crops        # 作物与解锁条件
python scripts/cli.py tools        # 工具链
python scripts/cli.py nutrition    # 拉取真实餐品热量表
python scripts/cli.py order --store 1450713 --codes 9900005466,4810
python scripts/cli.py plant lettuce
python scripts/cli.py grow
python scripts/cli.py harvest
python scripts/cli.py redeem lettuce
python scripts/cli.py buy sickle
python scripts/simulate.py 6       # 经济平衡验证 + 压力测试
```

**环境要求**：Python 3.8+，**仅标准库，无需 pip install**。

### 种植与收获

```bash
$ python scripts/cli.py plant lettuce
当前实际需要能量：1600 kcal（已扣除工具加成）

$ python scripts/cli.py grow
[████████████░░░░░░░░░░░░] 802/1600 kcal（50%）
```

## 核心设计原则

1. **农资金只能来自真实消费省额**。食材和券都不能变钱，否则经济会自我膨胀。
2. **兑换有两道闸门**：额度 ≤ 消费额的 25%，每周 ≤ 5 张。这是防通胀的生命线。
3. **生长只由能量推进**，与现实时间无关，不吃也不掉进度。
4. **工具按类型绑定**，种植工具不能用来养鸡。
5. **不替用户下单**。`create-order` 不在自动流程内，任何支付都由用户确认。
